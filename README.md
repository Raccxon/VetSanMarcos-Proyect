# VetSanMarcos

Aplicación web frontend para la gestión de servicios veterinarios de Veterinaria San Marcos.

## Tecnologías

- React 19
- Vite
- React Router
- Bootstrap 5
- React Leaflet / Leaflet
- Vitest
- React Testing Library
- jsdom
